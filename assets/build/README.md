# Profile artwork

`banner-light.svg`, `banner-dark.svg` (the header) and `btn-*.svg` (the link buttons) in `assets/`
are generated by `make_assets.py`. All text is converted to outlines, so the banner renders identically
on every device. The whip is one frame of a small position-based-dynamics simulation
(set `ANIMATE = True` in the script to bake the full motion into SMIL keyframes).

```sh
sh fetch_fonts.sh                        # once: Newsreader, Source Sans 3, Noto Serif KR (all SIL OFL)
python3 -m pip install fonttools uharfbuzz
python3 make_assets.py                   # rewrites ../banner-*.svg and ../btn-*.svg
```

Colors follow the website palette in `MosesAndLily.github.io/styles/tokens-light.scss` and `tokens-dark.scss`.
